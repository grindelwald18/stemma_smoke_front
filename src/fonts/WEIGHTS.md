# Использование весов шрифтов

## Схема использования весов

### SEITU (для заголовков):
- **Extra Light (200)** - для очень легких заголовков (не используется в текущей версии)
- **Regular (400)** - для обычных заголовков (не используется в текущей версии)
- **Medium (500)** - для основных заголовков (h1, h2, h3, h4, h5, h6)
- **Bold (700)** - для акцентных заголовков (не используется в текущей версии)

### Aptos (для основного текста):
- **Extra Light (200)** - используется Light как Extra Light, для очень легкого текста (не используется в текущей версии)
- **Regular (400)** - для основного текста (body, параграфы, input)
- **Medium (500)** - для акцентов (кнопки, ссылки, метки форм, меню)
- **Bold (700)** - для важных элементов (не используется в текущей версии)

## Текущее использование

### Заголовки (SEITU):
- Все заголовки (h1-h6): **Medium (500)**

### Основной текст (Aptos):
- Body, параграфы: **Regular (400)**
- Кнопки: **Medium (500)**
- Ссылки: **Medium (500)**
- Метки форм: **Medium (500)**
- Меню навигации: **Regular (400)**

## Примеры использования

```css
/* Заголовок */
h1 {
  font-family: 'SEITU', sans-serif;
  font-weight: 500; /* Medium */
}

/* Основной текст */
body {
  font-family: 'Aptos', sans-serif;
  font-weight: 400; /* Regular */
}

/* Кнопка */
.btn {
  font-family: 'Aptos', sans-serif;
  font-weight: 500; /* Medium */
}

/* Легкий текст (если понадобится) */
.light-text {
  font-family: 'Aptos', sans-serif;
  font-weight: 200; /* Extra Light */
}

/* Акцентный заголовок (если понадобится) */
.accent-heading {
  font-family: 'SEITU', sans-serif;
  font-weight: 700; /* Bold */
}
```
