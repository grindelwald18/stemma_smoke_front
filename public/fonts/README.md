# Инструкция по добавлению шрифтов

Для использования шрифтов SEITU и Aptos в проекте необходимо добавить файлы шрифтов в эту папку.

## Структура файлов

Поместите следующие файлы в папку `public/fonts/`:

### SEITU (для заголовков):

-   `SEITU-ExtraLight.woff2` (или `.woff`, `.ttf`)
-   `SEITU-Regular.woff2` (или `.woff`, `.ttf`)
-   `SEITU-Medium.woff2` (или `.woff`, `.ttf`)
-   `SEITU-Bold.woff2` (или `.woff`, `.ttf`)

### Aptos (для основного текста):

-   `Aptos-Light.woff2` (или `.woff`, `.ttf`) - используется как Extra Light (200)
-   `Aptos-Regular.woff2` (или `.woff`, `.ttf`) - Regular (400)
-   `Aptos-Medium.woff2` (или `.woff`, `.ttf`) - Medium (500)
-   `Aptos-Bold.woff2` (или `.woff`, `.ttf`) - Bold (700)

## Форматы файлов

Приоритет форматов:

1. `.woff2` (рекомендуется - лучшая компрессия)
2. `.woff` (хорошая компрессия)
3. `.ttf` (fallback)

## Fallback шрифты

Если файлы шрифтов не будут найдены, система автоматически использует:

-   **SEITU**: `Segoe UI Variable Display`, `Segoe UI`
-   **Aptos**: `Segoe UI Variable Text`, `Segoe UI`

Эти шрифты доступны в Windows 11 и будут использоваться как резервные варианты.

## Проверка подключения

После добавления файлов шрифтов проверьте в браузере:

1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Отфильтруйте по "Font"
4. Обновите страницу
5. Убедитесь, что файлы шрифтов загружаются

## Примечания

-   Файлы шрифтов должны быть в формате UTF-8
-   Рекомендуется использовать `.woff2` для лучшей производительности
-   Размер файлов должен быть оптимизирован для веб-использования
