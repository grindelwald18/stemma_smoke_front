# Stemma Smoke Front - Управление планограммами

React приложение для создания, редактирования и удаления планограмм сигаретных шкафов.

## Функциональность

- **Список планограмм** - просмотр всех планограмм с возможностью удаления
- **Создание планограммы** - создание новой планограммы с маппингом пушеров в СКЮ
- **Редактирование планограммы** - изменение существующей планограммы

## Сущности

### Cabinet (Шкаф)
Сигаретный шкаф, содержащий полки с пушерами.

### Shelf (Полка)
Полка в шкафу, содержащая пушеры (dispensers).

### Dispenser (Пушер)
Ряд на полке. Имеет ID, ширину и смещение по X.

### Planogram (Планограмма)
Планограмма содержит:
- ID шкафа, для которого она действует
- Timestamp - время валидности планограммы
- Mapping - маппинг пушеров в СКЮ (dispenser_id -> sku_id)
  - Если SKU ID = 0, то пушер должен быть пустым

### PlanogramMatchingResult
Отчет по сверке с планограммой, содержащий несоответствия.

### Discrepancy
Несоответствие размещения товара планограмме.

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build
```

## Использование

1. Откройте приложение в браузере (обычно http://localhost:5173)
2. На главной странице отображается список всех планограмм
3. Нажмите "Создать планограмму" для создания новой
4. Выберите шкаф и установите время валидности
5. Заполните маппинг пушеров в СКЮ (0 означает пустой пушер)
6. Для редактирования нажмите "Редактировать" на карточке планограммы
7. Для удаления нажмите "Удалить" (с подтверждением)
